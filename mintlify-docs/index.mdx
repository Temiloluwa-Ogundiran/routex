# RouteX API Docs

RouteX gives merchants one public payment API in test mode. These docs stay focused on the endpoints external developers use.

## What you need

- A test merchant workspace
- Your test secret key from the RouteX dashboard
- `Authorization: Bearer <test-secret-key>`

## Base URL

```bash
https://routexapi.xoroai.cloud
```

## Public endpoints

- `POST /api/v1/initiate`
- `GET /api/v1/transactions/verify`
- `POST /api/v1/payout`

## Request conventions

- Amounts are sent in customer-facing currency units.
- Omit `gateway_code` to let RouteX route automatically.
- Send `gateway_code` only when you want to force a gateway.
- Send `notification_url` when you want normalized webhook delivery.

## Webhooks

RouteX posts normalized events to your `notification_url` after provider confirmation. Every request includes `X-AGGREGATOR-SIGNATURE`.
