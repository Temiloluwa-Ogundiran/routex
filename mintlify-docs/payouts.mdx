# Payouts

Create a payout request and RouteX deducts it from the merchant balance directly.

## Request

| Field | Required | Description |
| --- | --- | --- |
| `reference` | Yes | Unique merchant payout reference. |
| `amount` | Yes | Amount to pay out in customer-facing units. |
| `currency` | Yes | Currency code such as `NGN`. |
| `customer.email` | Yes | Recipient email address. |
| `customer.name` | No | Recipient name if you have it. |
| `destination.bank_code` | Yes | Bank code for the destination account. |
| `destination.account_number` | Yes | Destination account number. |
| `metadata` | No | Optional payout metadata. |
| `narration` | No | Optional payout narration. |

## Example request

```json
{
  "reference": "PAYOUT_1001",
  "amount": 5000,
  "currency": "NGN",
  "customer": {
    "email": "recipient@example.com",
    "name": "Grace"
  },
  "destination": {
    "bank_code": "044",
    "account_number": "0123456789"
  },
  "metadata": {
    "batch": "march-settlement"
  },
  "narration": "Vendor settlement"
}
```

## Example response

```json
{
  "status": true,
  "message": "Payout simulated successfully",
  "reference": "PAYOUT_1001",
  "data": {
    "amount": 5000,
    "currency": "NGN",
    "fee": 50,
    "total_deducted": 5050,
    "balance_before": 20000,
    "balance_after": 14950,
    "reference": "PAYOUT_1001",
    "customer": {
      "email": "recipient@example.com",
      "name": "Grace"
    },
    "destination": {
      "bank_code": "044",
      "bank_name": "Access Bank",
      "account_number": "0123456789"
    }
  }
}
```

## Notes

- Payouts use the same merchant auth flow as collections.
- RouteX checks the wallet first, then records the payout internally.
- No external gateway is used for the payout flow.
